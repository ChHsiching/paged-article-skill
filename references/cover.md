# cover.md — 封面设计体系（改编自 beautiful-article）

封面是 3:4 图文构图，一眼传达"这篇讲什么 + 长什么气质"。它不是标题栏——它是**书封 / 杂志封面 / 唱片封套**。

封面 ≠ Hero：
- 封面 = 视觉钩子 + 风格定调（图主字辅）
- Hero（正文顶部）= 框定主题 + 读者收获（文字为主）

两者互补，不要做成同一件事。

## 硬约束（5 条 · 不可妥协）

1. **3:4 比例固定**。`aspect-ratio: 3/4`，内部元素用百分比 / 相对单位，不写死绝对像素。
2. **图文并茂**。**禁止纯文字封面**。必须同时具备：
   - **视觉主体**（SVG / CSS 几何 / 字体艺术 / 混搭，agent 自选）
   - **文字层**：至少一个标题，可加副题、小标签（type / date / kicker）
3. **主题忠实**。颜色 / 字号 / 边框 / 间距全用当前主题的 token 值（见 `themes.md`）。不写死 hex——切主题封面要跟着变。
4. **内容忠实**。视觉主体要呼应**正文主旨**，不是泛泛装饰。读完封面读者要能猜出文章在讲什么。例：
   - 讲"spec 是投影" → 封面是被划掉的 spec 纸 + 投影
   - 讲"缓存命中率" → 封面可以是命中率曲线
   - 讲"循环" → 封面可以是带箭头的循环图
5. **offline-first**。唯一硬禁：远程图片（`<img src="https://">`）。base64 raster 仅当配图模式是 user-assets / ai-generated。

## 5 个构图模板（选一个，不混搭）

| 模板 | 布局 | 适合 |
|---|---|---|
| **A · 上字下图** | 标题在上 1/3，视觉主体在下 2/3 | 教学 / 报告 / 大多数场景 |
| **B · 大字盖图** | 视觉铺满 3:4，超大标题叠在中/下 | 出版 / 叙事（**press / bodoni 推荐**） |
| **C · 上下分屏** | 上色块（带标题）+ 下视觉，一线分隔 | 数据 / 严谨（tufte / shannon） |
| **D · 满屏拼贴** | 视觉 = 多色块/形状铺满，文字嵌在一块里 | 当代 / 视觉（sottsass / bayer） |
| **E · 极简框** | 大量留白 + 细线框 + 居中标题 + 一个小视觉锚点 | 极简 / 严肃 / 哲学 |

**按主题推荐**：press/bodoni → B 或 E；tufte/shannon → C；sottsass/bayer → D；freddie/andy → A。

## 视觉技术（agent 自选，效果好就行）

封面的视觉主体**用什么技术由 agent 决定**——SVG / CSS / Canvas / 字体艺术 / 复杂合成 / 任意混搭。**没有"首选"**，只有"禁"：远程图片。

常见手法（启发，不是规定）：
- **概念隐喻 SVG**：文章核心概念画成一个低科技隐喻（如"被划掉的纸"= 可丢弃的 spec）
- **大字水印**：一个关键词放大到 400px+，opacity 0.05-0.08，做版式骨架
- **渐变遮罩**：底部 `linear-gradient` 从透明到纸色，让文字浮在背景上
- **印章/贴纸**：右下角一个圆形/方形小标记（如 GDD / END），呼应出版物扉页
- **几何线条**：细线、竖线、方框做结构，呼应"以线代框"

## 封面 5 条自检

写完封面，过一遍：

1. **图文都有吗**？不是纯文字？
2. **切主题会跟着变吗**？没有写死颜色/字体？
3. **看一眼能猜出文章讲什么吗**？视觉呼应正文主旨？
4. **3:4 比例下元素不溢出吗**？不同内容长度都撑得下？
5. **封面文字 ≠ 发布标题**？两者措辞不同（小红书规则）。

## 封面文字层结构（通用）

```
┌─────────────────────────────┐
│ EYEBROW · KICKER     SERIES │ ← 顶部小标签（主色 + 宽字距）
│                             │
│    [ SVG 视觉主体 ]          │ ← 中间图解区
│                             │
│                             │
│ 大标题（衬线/无衬线·加粗）    │ ← 底部文字层
│ 副标题 / lead（次要色）       │   （可能带渐变遮罩）
│ ─────────────────────────── │
│ 署名                  01/07 │ ← meta 行（等宽小字）
└─────────────────────────────┘
```

水印（大字低透明度）通常放右下角，从底层透上来。
